# โดรนพ่นยา – Exact Mockup Style
เวอร์ชันนี้สร้าง UI ใหม่ให้ยึดตามภาพตัวอย่างโดยตรง:
- หน้าหลักมีพื้นภาพทุ่งนา/โดรน
- ปุ่มใหญ่ 4 สี
- งานวันนี้แบ่งเช้า/บ่าย/เย็น
- เมนูล่าง 5 ปุ่ม: หน้าหลัก / งาน / การเงิน / สถิติ / ตั้งค่า
- หน้าบันทึกงานแบบฟอร์ม iPhone
- หน้ารายรับ-รายจ่าย
- หน้าสถิติรายลูกค้า
- ตั้งค่า/สำรอง/กู้คืน/CSV

ติดตั้ง: แตก ZIP > Deploy เป็น Site ใหม่บน Netlify > เปิด Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม

## V2
- ปรับหน้า Home ให้เหมือนภาพตัวอย่างมากขึ้น
- ใช้แบนเนอร์โดรน/ทุ่งนาแบบภาพตัวอย่าง
- ปุ่มเมนู 4 สีเรียง 4 ช่อง
- การ์ดงานวันนี้ / ตารางช่วงเช้า-บ่าย-เย็น / เมนูล่าง 5 ปุ่ม
- ย้ายคำแนะนำติดตั้งไปหน้า Settings

## V3
- แก้ภาพหัวแอปไม่ให้ล้นหรือโดนครอปบน iPhone
- ใช้ background-size: contain
- ปรับสัดส่วนแบนเนอร์แบบ responsive
- ปรับตำแหน่งการ์ดเมนู 4 สีให้พอดีกับแบนเนอร์ใหม่

## V5 Stable
- ย้อนฐานกลับไปใช้ V3 ที่เมนูต่าง ๆ ทำงานได้
- แก้เฉพาะช่องสถานที่ `location` ที่ชนกับ Safari
- ป้องกัน error จาก installCard ที่อาจไม่มีในหน้า
- ตรวจ syntax JavaScript ด้วย Node แล้ว
